# 物流运筹学 · 智能学伴

> 玻璃拟态 (Glassmorphism) 风格的闯关式学习助手

## 设计风格

- **玻璃拟态**：半透明毛玻璃面板 + 背景模糊
- **动态光晕**：紫/蓝/青/粉多色渐变光球浮动
- **细腻动效**：流光进度条、脉冲节点、弹性弹窗
- **暗色基调**：深蓝紫色系，降低视觉疲劳
- **SVG 图标**：线性图标替代 emoji，更精致

## 功能

| 功能 | 说明 |
|------|------|
| 地图闯关 | SVG 节点地图，连线为学习路径，通关后路线点亮 |
| 知识树导航 | 左侧文件夹分组，颜色编码，状态标记 |
| 答题闯关 | 选择/填空，即时反馈 + 解析 + 提示 |
| AI 诊断 | 掌握度雷达图 + 薄弱点进度条 + 复习建议 |
| 进度保存 | LocalStorage 自动存档 |

## 运行

双击 `index.html` 或用本地服务器：
```bash
python -m http.server 8080
```

## 技术栈

纯 HTML/CSS/JS，零依赖。Canvas 雷达图，SVG 地图。
