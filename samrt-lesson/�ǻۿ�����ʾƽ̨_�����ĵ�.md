## 演示参数 1（逐句对照）

> 原句：AI课堂分析平台支持对接校方已有教学平台线上课程，支持配置课堂活动记录功能，将已有教学平台线上课程发布的相关活动直接同步至AI课堂分析平台，以时间轴的形式呈现课堂发布的随堂练习等相关活动。同时支持直接跳转至教学平台的课程教学空间查看对应活动的参与情况，或直接发起主题讨论、分组任务等其他教学活动。

**演示路径（约 3 分钟）**
1. 「课程中心 → 对接课程配置」：页面顶部显示“已对接课程 3/3、同步策略：自动·每日”，表格每行展示教学平台课程号（如 JXP-C0231）。**要点**：任点一行「配置详情」，可勾选要同步的活动类型（随堂练习/即时测验/主题讨论/分组任务/课堂签到）与自动同步开关——这就是“支持配置课堂活动记录功能”。点「立即批量同步」演示真实同步。
2. 进入「课堂分析 → 课堂活动」：右上角有“教学平台同步”蓝色标签的活动，即已同步到平台的随堂练习等。**现场演示**：点「立即同步」，1 秒后新活动以“教学平台同步”标签出现在时间轴顶部，同时消息通知弹“已同步 N 项课堂活动”。
3. 时间轴演示：按日期分组的时间线，每条含活动类型、发布时间、周次、参与人数、来源；顶部筛选条可按课程/类型/来源/时间范围过滤。
4. 任点一条活动右侧「教学平台空间」→ 弹出内嵌“校方教学平台·课程教学空间”页面（带地址栏与“统一身份认证已通过”），展示该活动参与人数、提交率、平均分与参与名单——即“直接跳转教学平台课程空间查看参与情况”。
5. 点「发起活动」→ 选择类型“主题讨论 / 分组任务 / 随堂练习”等、填写标题并关联大纲知识点 → 「立即发布」后真实出现在时间轴并置顶。再点该活动「编辑/移除」演示可维护。

**被问到怎么答**
- “同步是真连校方教学平台吗？”→ 演示环境为本地模拟数据源，与教学平台之间的协议/接口均已按对接方案预留，现场演示的是完整交互闭环；生产环境通过统一身份认证 + 消息队列自动同步。
- “教学平台跳转是外部页面吗？”→ 我们与教学平台课程空间做了单点登录深链（保留活动上下文），现场以内嵌页面演示效果。
- “时间轴数据来源？”→ 校方教学平台发布的活动 → 平台课堂活动记录（自动/手动同步）→ 时间轴沉淀，可追溯原始活动。

## 演示参数 2（逐句对照）

> 原句：支持每堂课程的授课计划、大纲知识覆盖对比分析。支持自动匹配已有教学平台对应课程的授课计划进行授课计划覆盖率分析，包含授课知识点、匹配覆盖知识点的对比分析；支持基于课程大纲知识点开展知识点覆盖分析；支持输出AI课堂分析报告呈现知识点覆盖统计详情数据。

**演示路径（约 3.5 分钟）**
1. 「课堂分析 → 授课计划比对」：顶部统计卡显示“计划知识点 X 条、覆盖学时 23/46、授课计划覆盖率 50%”；主表逐条列出授课计划知识点、所属章节、计划周次、计划学时、大纲要求、平台课堂覆盖学时、匹配结果（完全覆盖/部分覆盖/未开课）。**要点**：这是“教学平台授课计划自动匹配 + 授课知识点/匹配覆盖知识点对比”。
2. 点「重新自动匹配」→ 按钮转“匹配中…”后 toast“授课计划自动匹配完成，覆盖率已更新”——体现自动匹配机制。
3. 任点一行「覆盖证据」→ 弹窗展示该知识点关联的随堂练习/测验等活动的标题、参与数、平均分——即“覆盖知识点对比分析的证据闭环”。
4. 「课堂分析 → 大纲覆盖分析」：按章节两级表格逐知识点展示大纲要求（掌握/熟悉/了解）、计划学时/已覆盖学时、关联活动数、最近覆盖时间与状态；顶部 conic-gradient 圆环给出“综合覆盖率”；部分覆盖与后续周次待开课知识点有明确提示。
5. 「课堂分析 → 分析报告」：选课程后自动生成《智慧课堂·AI课堂分析报告》：报告编号、授课计划覆盖率、大纲知识点覆盖统计详情表（每条知识点一行）、最佳表现知识点 TOP5、待补强/待开课知识点清单。点「下载报告」真实导出 TXT、点「打印报告」可打印。
6. （联动演示）切到“医学影像学（胸部影像诊断）”等其它课程，覆盖率与表格随之整体变化，说明数据按课程独立统计。

**被问到怎么答**
- “覆盖率怎么算？”→ 授课计划覆盖率 = 平台课堂已覆盖学时 ÷ 教学平台授课计划计划学时；大纲知识点覆盖 = 按“已覆盖(课时达标)/部分覆盖/待开课”三种状态逐点统计，证据来自课堂活动与授课记录。
- “未覆盖知识点会不会扣分？”→ 系统会区分“后续周次待开课”与“已到期仍未覆盖”，后者在报告“待补强知识点”中提醒教师补授，并可推送教学预警。
- “能否对每一堂课生成报告？”→ 报告按课程维度生成并覆盖全学期每堂课记录，支持课时/知识点维度下钻。

## 演示参数 3（逐句对照）

> 原句：相关录直播资源可直接对接校方现有教学平台，实现授课资源的灵活存储使用，支持教师管理所授课程视频资源的开放、访问权限，支持视频资源的在线剪辑并导出保存，也可直接同步至现有教学平台的云盘、资源库，实现资源在平台的自由调用。支持将教师在课堂授课过程中的语音实时转换为文字，并根据前后文语义动态纠正文字；支持实时翻译教师语音，识别及翻译语种包含中、英、德、法、日、俄、西班牙、韩、阿拉伯、葡萄牙、印第等多语种。

**演示路径（约 4 分钟）**
1. 「资源中心 → 直录播资源」：顶部统计“资源总数/已同步教学平台/开放范围/待处理”；列表按课程与类型（课堂实录/直播回放/微课/剪辑片段）组织。
2. 点视频「播放」→ 课堂实录播放器（可播放/暂停/倍速/拖进度，课件画面按时间推进，含 REC 标识）。
3. 点「访问权限」→ 选择开放范围（校内公开/课程班级/指定班级/私有）+ 开放能力（在线回看/下载等），保存后列表权限标签即时更新——即“管理视频资源开放、访问权限”。
4. 点「在线剪辑」→ 设置入点/出点 → 「导出剪辑」→ 生成“剪辑片段”资源入列表并标注素材来源——即“在线剪辑并导出保存”。
5. 对未同步资源点「同步教学平台」→ 状态变“已同步”，展示目标“教学平台·资源库/课程名/视频”与时间——即“同步至教学平台云盘、资源库”。
6. 「资源中心 → 语音转写与翻译」：点「开始实时转写」，语音逐句转成文字（带时间戳与字数统计）。
7. **语义纠正演示**：默认开启“语义纠错”，滚动到含误识的句子时，会出现绿色纠正标注“已按上下文语义纠正：误识‘满族废’→‘慢阻肺’（根据上下文语义纠正）”，底部“语义纠正 N 处”计数同步变化；关闭开关再转写则不做纠正。
8. **翻译演示**：右侧 11 个语种 chip（中文/英语/德语/法语/日语/俄语/西班牙语/韩语/阿拉伯语/葡萄牙语/印地语），点“日语”等任意语种，译文即时重译该句；同传延迟标识可见。结束转写后可「保存转写记录」，并「导出」含译文的 TXT。
9. （补充）“云端资源库”可再演示资源自由存储调用：上传/目录/权限/同步/删除。

**被问到怎么答**
- “识别与翻译是真实多语种引擎吗？”→ 演示环境内置课堂语音样例与多语种译文库用于现场走查；生产对接语音识别/机器翻译引擎，11 语种接口均已规划（含印地语等小语种，按需开通）。
- “剪辑会不会影响原视频？”→ 基于云端原始视频无损截取片段，生成独立“剪辑片段”资源，原视频不受影响。
- “同步到教学平台后在哪里取用？”→ 目标为教学平台云盘/资源库目录，教师与学生均可在平台内自由调用，双向授权可见。

## 演示参数 4（逐句对照）

> 原句：直录播视频直接对接学校现有评价系统的督导评价功能，实现界面统一的可视化配套使用，顶部栏展示课程、开课学院、教师、教室、班级、排课周、周进度及选课人数等字段数据，主界面可直接查看授课视频，同时支持对接已有评价系统的评价表，选择评价表进行打分评价，评价界面支持展示评价表基础信息，基础信息字号可进行大中小切换。整个页面主色调为紫色，同时页面的风格要简约大气。

**演示路径（约 3 分钟）**
1. 「督导评课 → 在线督导」：整页紫色主题（顶部紫色信息栏 + 紫色品牌体系，全平台无卡通图标、简约大气）。
2. 顶部信息栏展示 8 个字段：**课程 / 开课学院 / 授课教师 / 教室 / 班级 / 排课周 / 周进度 / 选课人数**。切换右上角节次下拉（不同课程/班级/周次），8 个字段联动更新——即“顶部栏字段数据”。
3. 主界面左侧为课堂实录播放器，可直接播放授课视频，页面标识“督导听课·课堂实录”“直连评价系统”。
4. 右侧选择评价表（下拉仅显示已启用的评价表，如《课堂教学质量评价表（督导听课版）》）→ 下方展示**评价表基础信息**（名称/版本/制定单位/适用范围/指标数/评分说明）。
5. **字号切换演示**：点字号切换「大/中/小」，基础信息与评价界面字号实时变化（大字 16.5px / 中字 14.5px / 小字 12.5px），右上角显示当前字号。
6. 逐项打分：输入分数后下方“合计/等级”实时计算；填满后点「提交评价」→ 确认 → 提示“评价已提交校方评价系统归档”，该节次显示“已提交，可重新评分”。
7. 「评价表管理」中可停用/新增/复制评价表，停用后“在线督导”下拉即刻消失——体现与评价系统的评价表对接。

**被问到怎么答**
- “督导与学校评价系统对接程度？”→ 视频直连 + 评价表同步 + 评价结果回传归档，评价界面与学校系统统一视觉、统一账号（统一身份认证）。
- “字号切换有什么意义？”→ 满足督导专家在不同设备（教室大屏/平板/手机）的阅读需求，基础信息字号大中小一键切换。
- “多督导同时评？”→ 支持督导组多人听课、各自打分互不干扰，后台按教师/课程汇总。

## 演示参数 3 补充：“资源在平台内的自由调用”如何实现与演示

> 对应原句“在线剪辑并导出保存，也可直接同步至现有教学平台的云盘、资源库，实现资源在平台的自由调用。”

**实现方式（三处落点）**
1. **同步到教学平台云盘 / 资源库**：资源行点「同步教学平台」→ 状态变“已同步”，展示目标路径（教学平台·资源库/课程名/类型）与时间——同步后可被教学平台侧任意引用；
2. **平台内调用（自由调用闭环）**：资源行新增「平台调用」，可选三个使用位置：
   - 绑定到**课堂活动**（作为课后/随堂资料附件，活动详情页可直接引用播放）；
   - 加入**课程资料区**（课程库/我的课程下课程可直接点播）；
   - 作为**大纲知识点覆盖证据**（在覆盖分析中作为统计证据）；
3. **调用可查可撤**：资源行显示“已被调用 N 处”，点击可查看每处引用并可“取消调用”。

**演示路径（约 1 分钟）**
1. 直录播资源 → 任选一个未同步资源点「同步教学平台」，观察“已同步教学平台 + 目标路径”。
2. 点「平台调用」→ 选择“绑定到课堂活动” → 任选一条活动 → 添加调用 → 回到资源列表可见“已被调用 1 处”；
3. 点击“已被调用 N 处”→ 弹窗列出调用位置，点「引用播放」可直接播放该资源、点「取消调用」可移除；
4. 到「课堂活动」打开该活动「参与详情」，可见该资源作为课后资料在活动内可直接引用（对应场景调用）。

**被问到怎么答**
- “调用与复制有什么区别？”→ 调用是引用（不改动原资源），权限、剪辑、同步状态全局一致；取消调用不影响原资源。
- “教学平台云盘里的副本能改吗？”→ 平台内编辑后重新同步即覆盖副本，保持两处一致。
- “能统计资源被使用情况吗？”→ 资源行实时显示被调用次数，操作日志留痕，可导出资源使用统计。
