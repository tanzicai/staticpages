### 本轮修掉的问题（可复用经验）
1. **jsdom 里 `App.go('#/x')` 是异步的**（靠 hashchange），紧跟其后查 DOM 会拿到旧页面 → 逐类型建点循环首轮失败。真实浏览器同理，eval 里改 hash 后必须 sleep 再操作。
2. **`U.confirm()` 的 `.then` 是微任务**，点完确认按钮立刻读 store 会读到旧值 → 验证需分两次 eval + sleep。
3. **CSS 栅格 `1fr` 的 auto 最小宽度会把页面撑破**（移动端 469px > 390px）。修法：全部改 `minmax(0,1fr)`，给 `.card/.view` 加 `min-width:0`，树节点文本 `overflow:hidden` + 省略号。
4. **`hidden` 属性会被 `display:flex` 覆盖** → 必须 `[hidden]{display:none!important}`。
5. 自定义 SVG 必须显式 `width/height`，否则 viewBox 撑满容器。
6. 自研 3D 引擎的拖拽验证：`canvas.toDataURL()` 要在 rAF 之后再取，同 tick 内取会得到相同像素（误判"拖拽无效"）。
7. 作业批改把"已批改数"用本次展示条数覆盖导致回退 → 改 `Math.max(已有, 本次)`。

## 第三轮：资源新增流程重做 + 数字教材承载改教师端 + 运营数据量级

### 改了什么
1. **资源库不再自动弹新增弹窗**（`views-course.js`）
   - 根因：`#/resources?add=1` 的 `add` 参数一直留在 hash 里，切 tab 触发 `render()` 会再次执行 `openResourceForm`，表现为"点本课程/其他课程资源就弹窗"。
   - 修法：`V.resources.mount` 里不再自动开表单，改为 `history.replaceState` 清参 + toast 引导点「新增资源」；保存后 pending 回填逻辑保留。
2. **新增资源表单三处细化**
   - `RES_TYPE_META` 类型→单位映射：video 时长 / doc 页数 / quiz 题量 / chapter 节数 / course 课时 / point 时长；`suggest(type, chapterIndex)` 按章节生成建议值，`change` 事件驱动 label、placeholder、value 同步。
   - 真实 `<input type="file">`（隐藏，挂到 `api.body`，不能用 `api.el`——`api.el` 是遮罩层，`.modal input[type=file]` 会查不到）。
   - 拖拽区 dragenter/dragover 高亮，drop 读 `dataTransfer.files[0]`；`fillFile()` 自动填名称/大小、按扩展名判类。
3. **`views-app.js` 整体重写**：手机壳 5 页签学生端 → 教师端「教材运行」（课前发放资源 / 课中 5 个活动控件 / 课后发放作业 / 发放记录 + 导出）。导航分组「移动端」→「数字教材」，项名「教学端 APP」→「教材运行」。`ClassViews` 追加导出 `openActivityResult` 供复用。
4. **运营数据降量级**：`learners` 基准 3120 → 206（14 天累到 279）、active 620 → 38~79；refs 各班级 18~38 人（合计 322）；`sync` 增量 23~52 → 3~8/天；DB `version` 3 → 4 强制重新播种。
5. **CSS**：`.act-grid.five` 类替代内联 5 列（内联样式会盖住媒体查询），`≤720px` 降 3 列；静态资源加 `?v=5` 防 CSS 缓存。

### 教训（可复用）
- **内联 grid 列数 = 媒体查询失效**：只要写了 `style="grid-template-columns:repeat(5,1fr)"`，后面的 `@media` 除非 `!important` 否则压不过；正确做法是出成类。
- **hash 参数驱动的一次性弹窗必须自我清理**：`?add=1`、`?open=1` 这类参数留在地址里，任何 `render()` 都会重放动作。打开后立刻 `replaceState` 去参。
- **`api.el` 是弹窗遮罩**（`ui.js`：`var api = { el: mask, body: mask.querySelector('.modal-b') }`），要插 DOM 到弹窗体里用 `api.body`。
- **Promise 型 confirm 的断言要等一拍**：同步代码里检查 `issues.length` 会在 `then` 回调前执行，误判为"没生效"。
- 用户要"教师发放"而不是"学生端演示"时，直接把手机壳学生视图删掉换成教师操作台，比在其上叠功能更省事，也更符合"像真实网站"的诉求。
