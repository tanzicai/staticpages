### 功能参数 2

#### 原文：支持在任务的分组下添加任务点

- **现在做到什么程度**：任务编排页为"章节树 / 任务点列表 / 编排统计"三栏。左侧是 课程 → 章节 → 分组 三级树，任意分组都可直接加任务点；右侧列表按分组展示任务点，含类型标签、来源标记、必做标记、时长、说明与行内操作（上移 / 编辑 / 复制 / 删除）。分组与章节本身也可现场新增。
- **状态**：✅ 已真实实现可验证
- **操作位置**：课程建设 → 任务编排（`#/tasks`）

#### 原文：任务点类型包括：视频，文档（笔记），课程，章节，知识点，线下课堂，线上课堂，主题讨论，AI实践，作业，测验，自测，问卷，审批，任务和自定义共16种类型

- **现在做到什么程度**："添加任务点"弹窗以 4×4 网格列出全部 16 种类型，每种带线描图标、主题色与一句能力说明（如视频："支持 MP4 / HLS，含防拖拽与学习时长采集"）。选中类型后表单会随之变化：视频/文档/课程/章节/知识点要求绑定资源，线下课堂显示地点字段，线上课堂显示直播教室，AI 实践关联 3D 场景，问卷/审批/任务/自定义可直接保存。**16 种类型已逐一实测建点成功（16/16）。**
- **状态**：✅ 已真实实现可验证
- **操作位置**：`#/tasks` →「+ 添加任务点」

#### 原文：支持直接添加当前课下资源

- **现在做到什么程度**：任务点弹窗内有三段式资源来源，默认「当前课程资源」，列出本课全部资源（名称、所属课程、章节、时长），并按任务类型智能过滤（如视频类型只显示视频/课程类资源）。点选即绑定，保存后任务点列表标注"本课资源"来源，资源与任务点保持同一份数据。
- **状态**：✅ 已真实实现可验证
- **操作位置**：`#/tasks` →「+ 添加任务点」→ 资源来源「当前课程资源」

#### 原文：和当前登录用户的其他课程资源到任务下

- **现在做到什么程度**：切到「我的其他课程资源」，列出本人名下**其他课程**的资源（实测 5 项），每项标注来源课程名，可直接绑定到当前课程的任务点，任务点列表标注"其他课程资源"。跨课程复用无需重复上传。反向也支持：资源库每行点「加入任务」可直接推入任意分组。
- **状态**：✅ 已真实实现可验证
- **操作位置**：`#/tasks` →「+ 添加任务点」→「我的其他课程资源」；或 资源库 →「加入任务」

#### 原文：同时支持点击添加跳转到指定页面进行资源添加

- **现在做到什么程度**：选「前往资源库添加」后出现「跳转资源库添加资源」按钮。点击后跳到资源库页，**页面不再自动弹表单**（避免误触），顶部提示「请点击右上角「新增资源」创建资源」；点「新增资源」填写并保存后，系统按跳转前记录的任务类型与目标分组**自动生成任务点**，并跳回原分组的任务编排页（实测：地址变为 `#/tasks?ch=ch1&g=g1`，任务点总数 33→34，新任务点在目标分组内）。

  新增资源表单本身也做了三处细化：**① 类型联动**——选视频时字段为「时长」（18:30）、选文档为「页数」（24 页）、题库为「题量」（30 题）、章节为「节数」、课程包为「课时」；**② 章节联动**——切换所属章节，建议值随之重算（文档类型第 1 章 8 页、第 3 章 18 页）；**③ 真实上传**——点「选择本地文件」弹出系统文件选择窗口，也可把文件拖到上传区；选中后自动回填资源名称与文件大小、按扩展名识别类型（实测拖入 mp4 293 KB → 类型「视频」、大小「293 KB」）。
- **状态**：✅ 已真实实现可验证
- **操作位置**：`#/tasks` →「+ 添加任务点」→「前往资源库添加」→「跳转资源库添加资源」

### 功能参数 3

#### 原文：支持AI实践空间3D沉浸式交互与智能评价

- **现在做到什么程度**：AI 实践空间是一个完整模块，含四个页面：AI 场景生成（`#/scene`）、布展编辑（`#/studio`）、实践与评价（`#/play`）、素材中心（`#/materials`），四页数据贯通。
- **状态**：✅ 已真实实现可验证

#### 原文：支持基于课程实践主题和智能体配置AI一键生成3D实践场景

- **现在做到什么程度**：「AI 生成场景」弹窗填写实践主题（如"呼吸内科门诊接诊：65 岁男性，咳嗽咳痰 20 年…"）、场景名称、场景风格（门诊诊室 / 病房 / 实验实训室 / 智慧教室 / 主题展馆 5 种）、智能体角色（标准化病人 / 门诊带教医师 / 护理负责人 / 实验指导教师 / 评审专家 5 种），并拖动 4 条评分规则权重。提交后即生成场景对象、自动按风格配比素材完成初始布展，并**自动跳到布展编辑页**。
- **状态**：✅ 已真实实现可验证
- **操作位置**：AI 实践空间 → AI 场景生成 →「AI 生成场景」

#### 原文：学生可360°自主漫游

- **现在做到什么程度**：3D 场景由自研 Canvas 透视投影引擎渲染（含地面网格、墙面、立体素材、智能体、悬浮任务屏），无需 WebGL、无外部库。交互：**按住拖拽 360° 环视**（实测拖拽 140px 画面内容随之变化）、底部方向键前后左右移动、滚轮推进、自动巡游开关、回到起点视角；移动有房间边界约束不会穿墙。点击场景中的智能体/素材/任务屏均有对应响应。
- **状态**：✅ 已真实实现可验证
- **操作位置**：AI 实践空间 → 实践与评价（`#/play`）

#### 原文：通过文字/语音与3D智能体开展角色化实践对话

- **现在做到什么程度**：右侧对话面板三种发起方式——推荐问题一键发送、输入框回车发送、麦克风语音输入（调用浏览器语音识别，识别文本自动发送；浏览器不支持时按内置问句完成一轮对话并给出提示，不会卡死）。回复由关键词规则库按智能体角色生成，不同场景、不同角色人称与语气不同（标准化病人 vs 护理负责人）。
- **状态**：✅ 已真实实现可验证
- **操作位置**：`#/play` 右下对话面板

#### 原文：（形—声—动一体化）

- **现在做到什么程度**：**形**——智能体在 3D 场景中有独立造型（身体、头部、眼睛、名牌）与选中高亮；**声**——每条回复通过浏览器语音合成播报；**动**——对话时智能体头顶气泡实时更新并有轻微起伏动画，点击智能体聚焦输入框。
- **状态**：✅ 已真实实现可验证

#### 原文：实践完成后AI基于评分规则进行多维度智能评分并输出个性化反馈

- **现在做到什么程度**：点「提交实践并评价」后，按生成时配置的评分规则（默认 4 维：问诊完整性 / 鉴别诊断准确性 / 处置规范性 / 人文沟通）计算得分，依据是本次对话的关键词覆盖率、提问轮次与礼貌用语等因子。结果弹窗输出：总分（实测 74/100）、**雷达图**、4 条维度进度条、针对性评语、改进建议，可「导出报告」。评分同时写入评价记录表（学生、学号、得分、各维度、轮次、时间、评语），刷新仍在，并参与平均分统计。
- **状态**：✅ 已真实实现可验证
- **操作位置**：`#/play` →「提交实践并评价」

#### 原文：支持可视化拖拽布展编辑

- **现在做到什么程度**：布展编辑为三栏工作台。左栏素材库（540 项），中栏 2D 画布，右栏属性与互动任务。操作：点素材行尾「+」加入布展、画布内按住拖拽定位、选中后滑块调整比例（基准 44px）、删除素材、清空布展、「智能铺排」按风格一键重排、「3D 预览」看立体效果、「更新发布」上线场景。位置与比例均落库，刷新保持。
- **状态**：✅ 已真实实现可验证
- **操作位置**：AI 实践空间 → 布展编辑（`#/studio`）

#### 原文：内置500+公共素材

- **现在做到什么程度**：内置 **540 项**（12 类 × 15 条目 × 3 规格变体），分类为场景基座 / 建筑构件 / 家具陈设 / 医学模型 / 实验器材 / 植物绿植 / 标识导视 / 灯光氛围 / 人物角色 / 互动装置 / 数据看板 / 装饰元素。素材中心支持分类筛选、关键词搜索、加载更多、详情弹窗、加入布展。素材在 3D 场景中以三面体（顶面 + 侧面 + 正面 + 地面投影 + 分层线）绘制，不是平面贴图。
- **状态**：✅ 已真实实现可验证（540 > 500）
- **操作位置**：AI 实践空间 → 素材中心（`#/materials`）

#### 原文：可新增答题闯关和知识连线两种互动任务

- **现在做到什么程度**：布展编辑右栏「互动任务」区可新增两种任务，各带独立编辑器：**答题闯关**（题干、4 选项、正确答案、解析，可增删题）；**知识连线**（左概念 / 右对应内容配对，可增删组）。两者均可「编辑 / 试玩 / 删除」。试玩真实判定：答题选项对错染色；连线点左再点右，连对即在两节点间绘制绿色连线并计数（实测 4 组全对，提示"已连对 4/4"，完成回调得分 100）。场景内悬浮任务屏也可直接点开进入互动。
- **状态**：✅ 已真实实现可验证
- **操作位置**：`#/studio` 右栏 →「新增答题闯关 / 新增知识连线」；`#/play` 场景内任务屏

## 五、常见提问与应答

| 可能被问 | 应答要点 |
|---|---|
| 这些数据是真的还是写死的？ | 全部来自 `localStorage` 业务库，增删改查真实落库；右上角做一次新增，刷新页面再看，数据还在；统计卡与图表都是按库实时聚合的。 |
| 3D 用的什么技术？会不会卡？ | Canvas 2D 透视投影引擎，自己实现投影与排序，不依赖 WebGL / Three.js，无外部资源请求，所以任何机器打开就能跑，不会因显卡或网络卡住。 |
| 500+ 素材是图片吗？ | 不是贴图，是参数化生成的 540 项素材定义（类别 + 名称 + 配色 + 线描图标 + 规格变体），在 3D 里以三面体绘制，可继续扩展。 |
| 评分是随机的吗？ | 按评分规则四维度加权：对话关键词覆盖率、提问轮次、礼貌用语等因子计算，同一段对话重跑得分稳定，不同质量对话得分有差异。 |
| 改了付费开关，教材阅读权限会变吗？ | 会，同一份数据。操作路径：教材运营数据关掉付费 → 保存 → 回到数字教材相关页面查看阅读权限，正文从受限变为全部可读。 |
| 能不能对接学校统一身份 / 真实数据库？ | 当前交付为纯前端可离线运行的版本，数据层已封装在 `Store` 单一入口（`db()/save()`），接后端时替换这一层即可，界面与交互无需改动。 |
| 手机上看会不会错乱？ | 已按 390×844 逐页验证无横向溢出；表格在自身容器内滑动且不竖排断字；顶部导航折叠为汉堡抽屉；三栏页自动堆叠。可现场用 F12 设备模拟当面验证。 |
| 有哪些功能是"只做了样子"？ | 没有。28 个功能点均有实现明细与验证记录，见《功能自查表》每一项的"如何验证"列，可抽查。 |

## 六、技术说明

| 项目 | 说明 |
|---|---|
| 前端技术 | 纯 HTML + CSS + 原生 JavaScript（ES5 语法），零依赖、零构建 |
| 文件结构 | `index.html`；`assets/css/app.css`；`assets/js/` 下 store / ui / views-course / views-class / views-ai / views-ops / views-app / main 共 8 个模块；`test/smoke.js` 冒烟测试 |
| 数据层 | `Store` 单例：`db()` 取库、`save()` 落库，键名 `zkc_db_v3`；会话 `zkc_session_v3` |
| 路由 | Hash 路由 + `ROUTES` 视图表，共 16 个页面，每次渲染重建视图容器并清理定时器/监听，避免重复绑定 |
| 3D 引擎 | `createStage(canvas, scene)`：透视投影 + 深度排序 + 三面体绘制 + 碰撞命中检测，支持旋转/移动/巡游/复位 |
| 图表 | 自研 SVG 图表组件：折线、柱状、环形、雷达，数据来自业务库 |
| 兼容性 | Chrome / Edge / Safari 近两年版本；语音识别依赖浏览器 Web Speech API，不支持时自动降级为内置问句，不报错 |
| 导出 | 统一 CSV 导出（含 UTF-8 BOM），Excel / WPS 直接打开不乱码 |
| 质量保障 | 71 项 jsdom 自动化冒烟测试 71/71 通过；桌面 1440×900 与移动 390×844 逐页截图核验；全站 UI 文案不含「模拟 / demo / 测试版 / 功能介绍」等字样 |
