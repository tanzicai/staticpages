GPIO · 有源蜂鸣器实验

PA11 控制 SS8050 · 发声 500 ms / 停止 500 ms

（1）电路原理图与三维开发板（可交互）

橙色：基极控制电流　蓝色：5V 负载电流　紫色：可能的关断续流。点击蜂鸣器或“开启声音”试听。

（2）实验原理解析

R18 = 1 kΩ · Q3 = SS8050（NPN） · D6 = 1N4148

Q3 的箭头位于发射极并向外，表示 NPN。正常导通：基极电流 B→E；负载电流 C→E。

D6 与 U6 并联，不与蜂鸣器串联。正常发声时反向截止；若关断时出现感性反冲，D6 可从下端阳极 A 向上端阴极 K 导通，形成局部续流。紫色短脉冲仅为保护机理示意，不是实测波形。

PA11R18 / 基极支路Q3 / 蜂鸣器供电D6U6
高电平PA11 → R18 → B → E → GND5V → U6 正端 → 负端 → C → E → GND反向截止持续发声 500 ms
低电平无持续正向基极电流Q3 截止，正常供电回路断开稳态截止；感性反冲时 A→K 续流停止 500 ms

开漏写 1 仅释放 PA11，不能主动提供基极电流；无外接上拉时不能可靠驱动，本页按无持续驱动处理。声音是低音量合成示意，频率不代表实际 U6 型号。

（3）虚拟示波器

PA11 电压Q3 导通：C→ED6 保护导通：A→KU6 发声状态

横轴：仿真时间（s）。Q3、D6 用 1 / 0 表示标注方向的导通状态，不表示电流大小。D6 关断后 30 ms 脉冲为放大的条件性示意。

29 Function: Set NVIC group
30 Input   : NVIC_Group:NVIC group 0~4, 5 groups in total

32 函数功能：设置中断分组
33 入口参数：NVIC_Group:NVIC分组 0~4 总共5组

36 void DIY_NVIC_PriorityGroupConfig(u8 NVIC_Group)	 
37 { 
38 	u32 temp,temp1;	  
39 	temp1=(~NVIC_Group)&0x07;//取后三位 Take the last three
40 	temp1<<=8;
41 	temp=SCB->AIRCR;  //读取先前的设置  Read previous settings
42 	temp&=0X0000F8FF; //清空先前分组   Clear previous groups
43 	temp|=0X05FA0000; //写入钥匙  Write the key
44 	temp|=temp1;	   
45 	SCB->AIRCR=temp;  //设置分组	  Set grouping
