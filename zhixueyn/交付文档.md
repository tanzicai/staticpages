## 三、逐项演示脚本（建议 12 分钟内）

### 演示点 1 · 移动端知识图谱与微课（约 3 分钟）
1. 打开 `http://127.0.0.1:8778/mobile/`，用 `student / student123` 登录。
2. 顶部**三模式**切换：**图谱模式**（16 个知识点按章节着色）→ **大纲模式**（章节目录）→ **学习地图模式**（学习进阶路径）。
3. 点任一知识点 → 进入微课，展示 **分析 / 学习内容 / 自测 / 资料 / 错题集 / 讨论** 六模块。
4. 「自测」选择范围「当前及前置知识点」→ 开始自测 → 作答 → 提交 → 显示得分。
5. 切「错题集」→ 答错题目自动归集，含正确答案与解析。
6. 顺带展示「学习内容」的 AI 助教答疑与「讨论」发帖。

### 演示点 2 · 课程门户与虚拟展厅（约 2.5 分钟）
1. 桌面端「课程门户与虚拟展厅」→ 填写课程名称/主讲/团队/学时学分/教材/简介。
2. 选择三维空间模板（如「科技感沉浸展厅」）→ 点「一键生成虚拟展厅」。
3. 展厅出现 3 个展区，点展区展示集成的课程视频 / 3D 模型 / 音频讲解 / 图文资料。
4. 点「自动嵌入课程门户」→ 切「门户预览」→ 看到门户内已嵌入虚拟展厅，并集成师资/教材/章节/图谱/AI 知识库/3D 资源，形成资源展示闭环。

### 演示点 3 · AI 科研助手（约 2.5 分钟）
页面为左右布局：上方**四个独立追踪模块**，下方**推荐文献 + 多文献对话**。
1. 四个独立模块分别演示（互不影响）：
   - **研究兴趣**：增删主题关键词 → 显示「自动追踪到 N 篇」
   - **学术期刊**：增删期刊名 → 按期刊命中
   - **学者**：增删学者名 → 按学者命中
   - **学术顶会**：增删会议名 → 按会议命中
2. 「自然语言追踪」输入一句话（如「施工安全 数字孪生」）→ 点「开始智能追踪」→ 命中文献。
3. 下方「AI 推荐文献」汇总各类推送（标注「来自 研究兴趣/学术期刊/学者/学术顶会」），**勾选 2 篇以上**（右上角实时显示已勾选数量）。
4. 点「发起多文献对话」→ 生成 **① 观点对比　② 研究方法对比　③ 结论对比　④ 摘要总结** + 综合摘要。
5. 任选文献切换 **APA / MLA / GB/T 7714** → 复制引用（期刊/会议自动区分 [J]/[C]）。

### 演示点 4 · AI 学情分析（约 3.5 分钟）
共 7 个页签，逐条对应原文要求：
1. **班级总览**：六维卡——视频完成情况 / 作业完成情况 / 考试完成情况 / 课堂活动参与 / 知识掌握情况 / 学生成绩分析（各带「关注并定时推送」按钮）；下方「班级各维度完成情况」柱状图、「学生成绩分布」环形图、「各章节知识掌握率」柱状图。
2. **作业与考试**：点任一作业/考试 → **题目作答分情况分析**（逐题正确率柱状图 + 分情况表：掌握良好 / 需巩固 / 失分集中 + AI 分析结论）。
3. **学生画像**：点学生 → 单人画像（完成率/掌握率/成绩环形 + 知识点掌握热力图）+ **AI 画像分析评价**。
4. **教学预警**：设置完成度/成绩阈值 → 学困生名单 → **一键提醒全部**（站内信 / 短信 / 电话 / 微信）；可「保存为常见问题」。
5. **AI 学情问答**（重点）：先选「分析范围」——
   - **班级整体**：可多选分析维度（视频完成 / 作业完成 / 考试完成 / 课堂活动参与 / 知识掌握 / 学生成绩分析）
   - **单份作业 / 考试**：选一份 → 题目作答分情况分析
   - **单个学生**：选一人 → 画像分析评价
   点「生成 AI 分析」输出结果，结果下方提供「保存为常见问题 / 设为定时推送 / 一键提醒学困生」。也可直接在输入框自由提问。
6. **常见问题**：保存的问题列表，可 **查看详情 / 重新提问 / 删除**，随时查看。
7. **定时推送**：勾选关注指标 + 频率（每日/每周/每月）+ 时间 + 接收方式 → 添加，列表可 **启停 / 删除**，实现自动接收关注数据。

### 演示点 5 · 资源智能安全检测（约 2 分钟）
1. 「审核规则配置」：增删敏感关键词、忽略词、黑白名单、图片名单。
2. 「资源检测」：点「开始智能检测」→ 12 项资源（文本/图片/文档/课程）给出结果，4 项判定风险（高风险 2 + 疑似 2），可「查看」明细与「屏蔽」处置。
3. 「风险统计」：按风险类型分布 + 用户垃圾发布量/发布率与风险等级。
4. 「文本纠错」：对示例文本智能校对，高亮 3 处问题并给出修改建议。

### 收尾 · 多角色切换（约 0.5 分钟）
顶栏「当前角色」依次切换 **平台管理员 / 课程教师 / 学生 / 教研督导**，展示菜单与功能权限随角色即时变化。

## 五、应答备查

- **是否真实运行平台？** 是真实可运行的前后端逻辑闭环（本地数据持久化），所有交互可点、可输入、可出结果，非截图/视频。
- **移动端如何访问？** 独立路由 `/mobile`，兼容 PC 与移动端浏览器；生产环境可嵌入微信公众号/移动 App。
- **AI 学情分析的「分析范围」怎么用？** 在「AI 学情问答」先选班级整体（多选维度）/ 单份作业考试 / 单个学生，再点「生成 AI 分析」，结果可直接保存为常见问题、设为定时推送或一键提醒学困生。
- **多角色怎么实现？** 角色驱动菜单权限与数据范围，切换即时生效且持久化。
