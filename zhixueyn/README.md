# 智课云 · AI+智慧课程资源建设与运行平台

面向「重庆工程职业技术大学《建设工程安全管理》《土力学与地基基础》人工智能+重点建设课程资源建设」项目的演示系统。纯 HTML + CSS + 原生 JavaScript，无框架、无构建工具，数据用 localStorage 持久化。

## 目录结构

```
smart-course-demo/
├── index.html                桌面端入口
├── css/
│   ├── style.css             桌面端样式（含图谱/门户/展厅/学情/安全组件）
│   └── mobile.css            移动端样式（构建源）
├── js/
│   ├── store.js              数据层：角色/菜单/课程/知识图谱/题库/文献/学情/安全规则
│   ├── app.js                桌面端应用（5 个演示项）
│   └── mobile.js             移动端应用（构建源）
├── mobile/
│   ├── index.html            移动端入口（独立路由 /mobile，**自包含单文件**）
│   └── index.template.html   移动端模板（构建源）
├── build-mobile.py           构建脚本：把 CSS/JS 内联进 mobile/index.html
├── 功能自查表.md              逐演示点实现与自验记录
└── 交付文档.md                现场演示脚本与应答备查
```

> **移动端为自包含单文件**：CSS 与 JS 已内联进 `mobile/index.html`，因此无论以「项目根」还是「mobile 目录」为根打开（含直接双击文件），都不会出现相对路径 404。
> 修改 `css/mobile.css`、`js/store.js` 或 `js/mobile.js` 后，运行 `python3 build-mobile.py` 重新生成移动端页面即可。

## 运行

```bash
cd smart-course-demo
python3 -m http.server 8778
```

- 桌面端：http://127.0.0.1:8778/
- 移动端：http://127.0.0.1:8778/mobile/

## 覆盖的评审演示点（产品演示 20 分）

1. **移动端知识图谱 + 微课**：图谱 / 大纲 / 学习地图三模式；微课含分析 / 学习内容 / 自测 / 资料 / 错题集 / 讨论。
2. **课程门户 + 虚拟展厅**：填课程信息 + 选三维模板 → 生成虚拟展厅 → 自动嵌入门户。
3. **AI 科研助手**：研究兴趣 / 学术期刊 / 学者 / 学术顶会**四类独立追踪**；自然语言追踪；推荐文献可勾选并驱动**多文献对话**（观点 / 研究方法 / 结论对比 + 摘要总结）；APA / MLA / GB-T7714 引用。
4. **AI 学情分析**：班级六维（视频 / 作业 / 考试完成、课堂活动参与、知识掌握、成绩分析）；单份作业 / 考试题目作答**分情况分析**；单人**画像评价**；学困生**一键提醒**；分析问题**保存为常见问题并随时查看**；关注数据**定时推送**；AI 问答支持**选择分析范围**。
5. **资源智能安全检测**：关键词 / 忽略词 / 黑白名单；垃圾发布量率；多维度审核（文本 / 图片 / 文档 / 课程）；文本纠错。

## 重置数据

清空浏览器 localStorage（或移动端「我的 → 恢复初始数据」）即可回到初始预置数据。
