# 物流运筹学 · 智能学伴

> 玻璃拟态 (Glassmorphism) 风格的闯关式学习助手

## 🎮 闯关机制

每个场景包含 **3~5 道题**，必须**全部答对**才算通关：

| 场景 | 知识点 | 题数 | 难度 |
|------|--------|------|------|
| 城市配送中心选址 | 线性规划建模 | 3题 | ⭐⭐ |
| 工厂生产计划优化 | 单纯形法 | 4题 | ⭐⭐⭐ |
| 跨省干线运输调度 | 产销平衡 | 3题 | ⭐⭐ |
| 多仓库物资调拨 | 表上作业法 | 5题 | ⭐⭐⭐⭐ |
| 物流园区设施布局 | 整数规划 | 3题 | ⭐⭐⭐ |
| 快递网点路径规划 | 动态规划 | 4题 | ⭐⭐⭐ |
| 生鲜冷链库存策略 | EOQ模型 | 3题 | ⭐⭐ |

**共 7 个场景，25 道题目**

### 答题流程
1. 点击地图节点 / 左侧知识树 → 进入场景
2. 依次作答 3~5 道题
3. 每题即时反馈（✅ 正确→下一题 / ❌ 错误→显示解析后自动继续）
4. **全部答对** → 🎉 场景通关！地图路线点亮
5. 有错题 → 💪 显示错题回顾，可重新挑战本关

### 进度追踪
- 顶部进度条：已通关数 / 总场景数
- 答题区进度条 + 小圆点：当前题位置
- AI 诊断报告：知识点掌握度雷达图 + 薄弱点分析 + 复习建议

## 运行

双击 `index.html` 或用本地服务器：
```bash
python -m http.server 8080
```

## 技术栈

纯 HTML/CSS/JS，零依赖。Canvas 雷达图，SVG 地图。

## 数据存储

`localStorage` 自动存档：通关记录、答题历史、薄弱知识点统计。
