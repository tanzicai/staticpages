（2）实验原理解析

R15 = 10 kΩ · D7 = Blue

开关是 GPIO 输出级的原理等效图；开漏没有主动拉高的上管，本板这条 LED 支路没有外接上拉。

电流采用简化模型：VDD = 3.3 V，假设蓝色 D7 正向压降 Vf = 3.0 V，I ≈ (3.3 − 3.0) / 10 kΩ = 0.030 mA。原图确为 10 kΩ；此值为示意估算，真实电流、亮度取决于 LED 的 I–V 特性及 GPIO 压降。

模式 / 写入PB3R15 → D7 → GNDLED
推挽 / 1上管导通，输出约 3.3 VPB3 供电，R15 限流，D7 正向导通，电流回到 GND亮
推挽 / 0下管导通，输出约 0 V支路没有正向驱动电压，稳态电流约 0灭
开漏 / 1下管关闭，高阻 Z（不等于高电平）没有上拉电源提供持续电流；引脚电压不保证灭（稳态模型）
开漏 / 0下管导通，输出约 0 V无正向电流灭

初始化还需开启 GPIOB 时钟。PB3 默认承担 JTAG 功能，工程 bsp_init() 通过 JTAG_Set() 释放 JTAG、保留 SWD，之后配置 PB3。GPIO_Speed_2MHz 是输出速度档位，不是闪烁频率。

（3）虚拟示波器

CH1 · PB3 电压（V）CH2 · 支路电流（mA，估算）CH3 · LED 状态（1 / 0）

写入通路

GPIO_SetBits() 写 BSRR = 0x00000008，置 ODR3；GPIO_ResetBits() 写 BRR = 0x00000008，清 ODR3。写 1 是执行命令，不能把 BSRR / BRR 当作持续电平。

读回通路

ODR 读取输出锁存值；IDR 读取输入采样结果。推挽稳态时通常一致；开漏写 1 是高阻，IDR 不保证为 1。这里的读取是附加观察操作，原主循环没有读取语句。

18  void JTAG_Set(u8 mode)
19  {
20  	u32 temp;
21  	temp=mode;
22  	temp<<=25;
23  	RCC->APB2ENR|=1<<0;     //开启辅助时钟	  Activate auxiliary clock  
24  	AFIO->MAPR&=0XF8FFFFFF; //清除MAPR的[26:24] Clear MAPR [26:24]
25  	AFIO->MAPR|=temp;       //设置jtag模式 Set jtag mode
26  }

30  Function: Set NVIC group
31  Input   : NVIC_Group
32  Output  : none
33  函数功能：设置中断分组
34  入口参数：NVIC_Group:NVIC分组 0~4 总共5组

37  void DIY_NVIC_PriorityGroupConfig(u8 NVIC_Group)	 
38  { 
39  	u32 temp,temp1;	  
40  	temp1=(~NVIC_Group)&0x07;//取后三位 Take the last three
41  	temp1<<=8;
42  	temp=SCB->AIRCR;  //读取先前的设置  Read previous settings
43  	temp&=0X0000F8FF; //清空先前分组   Clear previous groups
44  	temp|=0X05FA0000; //写入钥匙  Write the key
45  	temp|=temp1;	   
46  	SCB->AIRCR=temp;  //设置分组	  Set grouping   	  				   
47  }
